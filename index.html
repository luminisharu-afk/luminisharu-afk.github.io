About

문제를 구조화하고, 실행 가능한 제품으로 옮깁니다.

복잡한 요구사항을 작은 단위로 나누고, 사용자에게 필요한 기능부터 안정적으로 구현하는 일을 좋아합니다. 화면의 디테일과 데이터 흐름을 함께 보며, 팀이 계속 유지보수할 수 있는 코드를 지향합니다.

이 페이지는 GitHub Pages에 바로 배포할 수 있는 정적 포트폴리오입니다. 소개, 기술 스택, 대표 프로젝트, 연락처를 본인 정보로 교체하면 개인 사이트로 사용할 수 있습니다.
